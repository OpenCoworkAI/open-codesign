Align explicit native HTML generation and comment revisions with the host-declared source identity. Native prompts and tools use the exact primary path, advertise and enforce compatible methods and scaffolds, select additive native method variants, and omit bundled virtual JSX resources without removing workspace files. HTML scaffolds preserve declared entry paths, including `.htm`, and auxiliary scaffolds cannot overwrite the primary source through extension normalization.

Native tweak discovery targets the declared source and describes authored bindings rather than promising a host-panel bridge. Existing legacy generation and user template customizations remain supported. This does not add a deterministic HTML editor, native live tweak-panel binding, or model-quality guarantees.
