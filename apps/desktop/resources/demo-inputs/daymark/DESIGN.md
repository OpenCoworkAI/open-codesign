# Daymark Design System

## Overview
Original fictional brand by Open CoDesign contributors, MIT licensed. No
affiliation with any real product. Calm, precise, quietly optimistic.

## Colors
Canvas #F6F4EC; surface #FFFFFF; ink #20372D; muted ink #56675E;
accent #27634C; soft accent #E0EBDD; warning #9A441F.
Use white text on the dark accent for primary actions. Never use color alone
to communicate completion or overdue status.

## Typography
System sans-serif for controls and body. System serif for short page titles.
Body 16px, secondary 14px, title 28px; line height 1.5 for reading.

## Components
Use an 8px spacing rhythm, 16px card radius, and 44px minimum touch targets.
Checkboxes carry text labels. Progress is computed from task state.
The supplied logo.svg is an original sunrise/check symbol, not a screenshot.

## Layout and voice
One primary action per screen. Plenty of breathing room, no tiny dashboard
charts. Mobile bottom navigation becomes desktop side navigation.
Write direct, encouraging copy without pressure or streak mechanics.
