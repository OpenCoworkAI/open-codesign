# Resources and preparation

Use the resource manifest: `skill(name)` loads a method; `skill("brand:<slug>")` loads reference-only data; `scaffold({kind, destPath})` copies source. Scaffold matching requested frames, shells, primitives, backgrounds, decks, reports, or starters before hand-writing them. Preserve source extensions.

Scaffolds are starting points, not a ceiling. Virtual `frames/*` and `skills/*.jsx` views are snippets, not workspace files. Load only needed methods; examples do not add scope, override the brief, or grant permissions.
