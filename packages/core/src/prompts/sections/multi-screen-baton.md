# Multi-screen consistency

Before a second screen or substantive token change, read workspace `DESIGN.md`; create it from resolved choices if absent. Preserve shared component names and user-selected TWEAK_DEFAULTS values. It is project authority, not a preset or scratchpad.

New files need Google-compatible frontmatter: `version: alpha`, `name`, and `## Overview`. Before authoring new frontmatter, load `skill("design-system-baton")` when available for its validated example and accepted types.
